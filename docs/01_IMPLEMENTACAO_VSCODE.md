# Implementação no VS Code

## 1. Abrir projeto

Abra no VS Code a pasta:

```text
FX_AI_HUB_AI_ADVANCED_V3
```

## 2. Terminal

Use CMD no terminal do VS Code.

## 3. Setup

```bat
scripts\01_setup_backend_windows.bat
```

## 4. Rodar backend

```bat
scripts\02_run_backend_windows.bat
```

Acesse:

```text
http://127.0.0.1:8000/docs
```

## 5. Testar API

No Swagger, rode:

- `/rates/collect`
- `/ml/forecast-all`
- `/recommendations/all`
- `/reports/generate`
- `/agents/run-enterprise-cycle`

## 6. Rodar frontend

```bat
scripts\03_run_frontend_windows.bat
```

Acesse:

```text
http://localhost:5173
```
